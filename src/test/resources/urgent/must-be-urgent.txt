# 자해·자살
아이가 요즘 자해를 하는 것 같아요.
우리 아이가 죽고 싶다는 말을 했어요.
아이가 죽고싶다고 적어 둔 메모를 발견했습니다.
극단적 선택을 할까 봐 너무 걱정됩니다.
손목을 긋는 걸 봤어요.
아이가 사라지고 싶다고 했어요.

# 학대·폭행
아이 몸에 멍이 여러 군데 있는데 선생님은 알고 계셨나요?
친구한테 맞고 왔다고 하는데 확인 부탁드립니다.
집에서 아이를 때렸다는 이야기를 들었어요.
아이가 학교에서 폭행을 당한 것 같습니다.
아동 학대가 의심됩니다.

# 성적 피해
성추행을 당했다고 말하는데 어떻게 해야 할지 모르겠어요.
아이가 성희롱을 당했다고 합니다.

# 실종·가출
아이가 어제부터 집에 안 들어왔어요.
가출한 것 같습니다.
오늘 학교에 갔는데 연락이 안 돼요.

# 위협·흉기
친구가 칼을 들고 있었다고 해요.
누군가에게 협박을 받고 있대요.

# 괴롭힘
학교폭력을 당하고 있는 것 같아요.
반에서 왕따를 당한다고 합니다.
