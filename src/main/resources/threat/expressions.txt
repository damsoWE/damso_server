# 위협·폭언 표현 목록
#
# [초안] 팀 리뷰 전이다. 머지 전에 리뷰한 사람·날짜를 PR 설명에 적는다.
#
# - 한 줄에 표현 하나. 빈 줄과 '#'으로 시작하는 줄은 무시한다.
# - 판정 방식(ThreatRule): 소문자·전각→반각으로 맞춘 뒤, 표현이 "어절의 시작"에서 시작할 때만 맞는다.
#   그래서 '모가지'는 "아이 고모가 지금"에, '병신'은 "질병 신고서"에 걸리지 않는다.
# - 띄어쓰기 차이는 표현에 공백을 둔 자리에서만 허용한다. "가만 두지 않겠" 은 "가만두지 않겠"·"가만 두지않겠"과 맞는다.
#   공백이 없는 "애새끼" 는 "애 새끼손가락"과 맞지 않는다. 그러니 띄어 쓸 수 있는 자리에는 공백을 넣어 둔다.
# - 오탐을 줄이는 쪽으로 둔다. 분명한 위협·폭언만 넣는다. 같은 말이 피해 호소·걱정·안전 부탁에도 쓰이면
#   위협으로 읽히는 활용형(예: "~하겠", "~해 드", "~할 거")까지 넣어 좁힌다. 받침이 붙으면 다른 글자가 되므로
#   ("드리" ≠ "드릴") 활용 어미 앞 글자에서 끊는다.
#   짧은 어간("시발" → "시발점", "꺼져" → "불이 꺼져", "새끼" → "새끼손가락")은 넣지 않는다.
# - 남이 한 말을 전하는 문장은 표시하지 않는다(PR #13 리뷰 결정). 표현 바로 뒤에 인용·전언 표지("~라고 했/하셨",
#   "~라는 말/소리", "~래요", "~했대요")가 오면 ThreatRule이 그 자리를 건너뛴다. 그러니 표현은 인용 어미 앞에서 끊는다.
# - 알려진 한계: 글자마다 띄어 쓰거나("가 만 두 지") 기호를 끼운 우회는 잡지 못한다(spec Edge Cases).
# - 교육청 민원·면담 요청·교장 상담·정식 이의 제기 같은 정당한 의사 표현에 걸릴 수 있는 표현은 넣지 않는다.
# - 긴급 목록(src/main/resources/urgent/expressions.txt)과 겹치는 표현은 넣지 않는다. 그런 문의는 긴급으로만 처리되어
#   이 목록의 항목이 쓰이지 않는다(협박·위협·죽이겠·죽여버리·칼을·흉기·학교폭력 등). 긴급 목록을 바꿀 때도
#   ThreatRuleTest의 "겹침 금지" 테스트가 함께 돈다.
# - 이 파일은 코드와 같이 PR 리뷰로만 바꾼다. 목록이 비면 서버는 기동을 거부한다.
# - 회귀 테스트: ThreatRuleTest, src/test/resources/threat/must-flag.txt(반드시 표시),
#   src/test/resources/threat/must-not-flag.txt(절대 표시 안 함). 표현을 지우거나 더할 때는 세 곳을 같이 본다.
